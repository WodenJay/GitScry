# Security Policy

## Supported Versions

GitScry is currently under active development. Security fixes are provided for the latest release and the current `main` branch.

## Reporting a Vulnerability

If you discover a security vulnerability in GitScry, please do **not** report it through a public GitHub issue.

Instead, please report it privately through GitHub's **Security Advisories**:

1. Go to the repository's **Security** tab.
2. Select **Advisories**.
3. Click **Report a vulnerability**.

Please include, when possible:

- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any suggested fix or mitigation

I will review the report and respond as soon as reasonably possible.

Please avoid publicly disclosing the vulnerability until a fix has been released.
